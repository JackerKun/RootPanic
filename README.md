# ROOT//PANIC：午夜告警

> 面向 IT 从业者与策略玩家的近未来技术危机 Roguelite 游戏。

你是接管失控数字系统的技术指挥官。除了处理生产事故，还需要追查异常代码提交、修复并发缺陷，并逐步进入安全攻防、数据救援、网络战争与 AI 失控等不同技术战场。

项目使用 TypeScript、Vite、DOM、SVG 与 Canvas 实现，构建后为纯静态网页；同时提供 PWA 与 Tauri 桌面封装，适配 PC、平板和手机。

当前阶段：`WEB/PWA FEATURE COMPLETE / 内容扩充与平衡阶段`

除 Tauri 打包、签名与商店发布外，Web/PWA 的完整玩法闭环已经完成。

## 当前可玩内容

- 五名职业指挥官选择及职业被动。
- 六节点 SVG 服务拓扑与依赖链。
- 实时事故生成、扩散、升级、SLA 损失和胜负结算。
- 30 类事故、事故链传播和 20 条可执行操作。
- 12 个局内升级与三选一构筑。
- 19 个剧情章节，包含系统抢修、代码追凶和 10 个多机制交互任务，以及无尽值班和每日固定 Seed 挑战。
- “幽灵提交”代码追凶任务：文件树、Git 历史、代码阅读、调用栈、证据板、并发测试、候选补丁和部署门禁。
- “断裂链路”网络接线：拖动或依次点击节点，移除过载链路并建立容灾路径。
- 日志取证与 Git 合并：将日志、证据和代码片段拖入正确决策区域。
- 查询计划与发布流水线：拖动步骤排序，验证依赖与执行顺序。
- 权限迷宫与 AI 审判：切断攻击路径，隔离提示词注入并保留可验证证据。
- 调度风暴、策略矩阵与零点载波：拖放容器工作负载、切换零信任规则、使用滑块校准最终隔离信号。
- 交互任务统一支持撤销、重置、约束检查、失败惩罚、帮助提示、触摸替代操作和独立结算。
- 指挥中心等级、五职业科技树、成就和场景解锁。
- 战术暂停、二倍速、双语切换和响应式布局。
- 五维事故评分、综合等级和本地职业成长。
- 自适应合成音轨、操作提示音、章节通讯和多结局文本。
- 存档码与事故战报导入导出。
- PWA 清单、离线缓存与 Tauri 桌面工程配置。

## 本地运行

环境要求：Node.js 20、22 或 24 LTS，npm 10 以上。

```bash
npm install
npm run dev
```

开发服务器会打印实际地址，通常为 `http://127.0.0.1:5173/`。需要直接测试全部章节时使用 `?test=1`；同时兼容本地开发时误写成的 `/test=1` 路径。测试模式使用独立临时存档，不覆盖正常进度。

生产构建与测试：

```bash
npm run build
npm test
npm run preview
```

`npm run build` 产物位于 `dist/`，可以直接部署到任意静态站点。具体配置见[部署与 PWA 指南](docs/DEPLOYMENT.md)。

Tauri 桌面开发需要额外安装 Rust 和平台对应的系统依赖：

```bash
npm run tauri dev
```

- IT 人一眼能懂的事故、梗、命令和系统状态。
- 标准局 10～15 分钟，兼顾移动端与完整策略节奏。
- “读告警 → 找根因 → 执行操作 → 控制风险”的高压决策体验。
- 终端、拓扑图、实时日志与霓虹 HUD 构成的专业科幻 UI。
- 每局随机事件、服务拓扑和升级组合，具备重复游玩价值。
- PC 支持点击、键盘与拖放；手机支持点击配对、上下箭头和触摸分类，使用同一套游戏规则。
- 纯静态、无账号、默认离线、本地保存进度。

## 游戏一句话说明

在不断恶化的系统事故中，根据日志与指标识别根因，使用有限的行动点执行正确操作，让所有核心服务撑到值班结束。

## 目标平台

| 平台 | 目标体验 |
| --- | --- |
| PC 浏览器 | 1440×900 为设计基准，支持鼠标和键盘快捷键 |
| 平板 | 双栏或折叠侧栏，支持触控和横屏 |
| 手机 | 横竖屏均可运行，以横屏战术界面为主要体验 |
| 静态托管 | GitHub Pages、Cloudflare Pages、Nginx、任意静态空间 |
| 离线 | Service Worker 缓存核心资源，无网络也能继续游戏 |

## 设计原则

1. **先好玩，再真实。** 技术概念必须为决策服务，不模拟真实终端的全部复杂度。
2. **信息密度高，但层级清楚。** 玩家要感到自己在控制复杂系统，而不是阅读一堵文字墙。
3. **失败可解释。** 每次失败都能看到事故链、错误决策和改进方向。
4. **手机不是缩小版 PC。** 手机界面重新编排，只保留当前决策最需要的信息。
5. **数据驱动。** 事故、操作、升级和文本独立于引擎，便于长期增加内容。
6. **零后端也完整。** 核心玩法、存档、设置和统计全部可以在浏览器本地运行。

## 第一版成功标准

- 新玩家不看说明，也能在 60 秒内完成第一次操作。
- 一局可以完整开始、进行、胜利或失败，并正确结算。
- 当前完整内容包含 5 个职业、19 个剧情章节、30 类以上事故和 20 条以上操作。
- PC 与 390px 宽手机均可完整操作，没有横向溢出。
- 60 FPS 目标设备上动画流畅，关闭特效后低性能设备仍可运行。
- 刷新页面不会丢失设置、解锁和最近一局的统计。
- 游戏逻辑可以在没有 DOM 的情况下执行自动测试。
