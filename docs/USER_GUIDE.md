# 玩家使用指南

本文面向第一次进入 `ROOT//PANIC：午夜告警` 的玩家。开发者快速测试请直接阅读[通关与测试指南](TESTING_GUIDE.md)。

## 1. 开始游戏

1. 选择指挥官。五个职业共享剧情进度，但拥有不同初始优势与科技树。
2. 选择任务场景。灰色章节需要获得足够 `Knowledge` 后解锁。
3. 选择剧情、无尽或每日模式；部分特殊任务只使用自己的固定规则。
4. 点击“授权接管”进入任务。

第一次进入运维关卡会显示四步教学，可以随时跳过。右上角 `?` 是上下文帮助开关，再次点击会关闭提示。

## 2. 三类任务

### 2.1 系统抢修

观察事故队列、服务拓扑、节点指标和事件流。先选择事故或服务，再执行诊断、扩容、重启、回滚、隔离等指令。目标是在倒计时结束前处理足够事故，并让 SLA 保持在章节要求以上。

- P4 和剩余时间最短的事故优先。
- 未确认事故先执行“链路诊断”。
- 指令消耗专注度或预算，也可能处于冷却中。
- PC 可以把可用指令卡直接拖到拓扑节点。
- 拓扑右上角支持缩小、复位和放大，鼠标滚轮也可缩放。

### 2.2 代码追凶

“幽灵提交”要求检查文件、提交历史、调用栈与测试结果。收集证据后选择候选补丁，必须先通过测试门禁才能部署。错误调查和错误补丁会降低稳定度。

### 2.3 交互任务

第 10～19 章使用七种交互方式：

| 方式 | PC | 手机与键盘替代操作 |
| --- | --- | --- |
| 网络连接 | 从一个节点拖到另一个节点；点击连线切换 | 依次点击两个节点 |
| 权限隔离 | 点击攻击路径连线 | 聚焦连线后按 Enter/空格 |
| 证据分类 | 把卡片拖入目标区 | 先点卡片，再点目标区 |
| 流程排序 | 拖动步骤到目标位置 | 使用每个步骤右侧上下箭头 |
| 资源调度 | 把工作负载拖到计算节点 | 先点工作负载，再点节点 |
| 规则矩阵 | 点击规则卡切换 ON/OFF | 聚焦规则后按 Enter/空格 |
| 信号校准 | 拖动频率、相位、增益和门限滑块 | 使用方向键精调滑块 |

左侧是任务说明，中间是工作区，右侧是必须满足的约束。所有操作都可以撤销或重置；确认全部目标后点击“执行验证”。验证失败会显示原因并扣除稳定度。

## 3. 通用控制

| 控制 | 作用 |
| --- | --- |
| `?` | 打开或关闭当前任务提示 |
| `A+` | 切换舒适大字与紧凑显示 |
| `← HQ` | 主动退出当前关卡并返回指挥中心；不记录失败，也不会结算奖励 |
| `♪ / ×` | 开启或关闭音频 |
| `中 / EN` | 切换中文与英文 |
| `Space` | 运维任务暂停或继续 |
| 数字键 | 执行当前任务对应的前几项指令 |
| `Esc` | 关闭帮助或展开的日志面板 |
| `Tab`、`Enter`、空格 | 键盘导航和激活交互项 |

每日挑战不能使用战术暂停。输入框获得焦点时，空格不会触发暂停。

## 4. 成长与存档

- 完成任务会获得知识点、职业经验、技能点、成绩记录和 AI 档案。
- 胜利结算页会显示本局奖励、下一章节及其解锁状态；已解锁时可以直接继续，否则会显示尚缺的 Knowledge。
- “返回指挥中心”会回到选关页；“重玩本关/重新挑战”只会重新开始当前章节。
- 指挥中心可以购买五个职业的永久技能。
- 正常存档保存在当前站点来源的 `localStorage` 中；更换域名、端口或浏览器相当于新的本地存档。
- “导出存档”会生成可复制的存档码；建议在清理浏览器数据或更换部署地址前先导出。
- 测试模式 `?test=1` 使用内存中的增强档案，不覆盖正常存档。

## 5. 手机使用建议

- 竖屏会把任务面板纵向排列，底部关键操作栏保持可见。
- 横屏可显示更多拓扑与卡片，但不是通关的必要条件。
- 不要依赖悬停；所有核心信息都可以点击查看。
- 若页面文字太密集，使用顶部 `A+`。
- iOS 或 Android 安装为 PWA 后可以全屏运行；首次缓存完成后可离线启动。

## 6. 常见问题

### 刷新后进度不见了

确认访问地址的协议、域名和端口是否改变。浏览器按来源隔离本地存储，例如 `localhost:5173` 与 `127.0.0.1:5173` 是两个不同存档。

### 无法安装或离线运行

生产环境必须通过 HTTPS 提供；`localhost` 是浏览器允许的开发例外。首次访问时仍需联网下载核心资源。

### 拖动在手机上无效

使用触摸替代操作：分类任务“点卡片→点目标区”，网络任务“依次点两个节点”，排序任务使用上下箭头。

### 不知道下一步做什么

点击右上角 `?`。运维任务会推荐当前事故、目标节点和指令；交互任务会给出当前关卡的解题方向。
